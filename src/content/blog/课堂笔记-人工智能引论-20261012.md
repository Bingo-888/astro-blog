## （复习）Python 模块与库

模块是一个有函数和变量的Python源代码文件。库则是许多模块的集合，完成特定的功能。

```python
import 库名
库名.函数名(输入值)
# 导入整个库，此时调用库中的函数需要在前面加库名
import 库名 as 别名
别名.函数名(输入值)
# 导入整个库并别名
from 库名 import 函数名
函数名(输入值)
# 从某个库中导入特定函数，此时调用库中的函数无需在前面加库名
```

Python内置的标准库：random / math

Python常见的第三方库：pandas / numpy

## Python 类和对象

- 类：对象的模板，定义这个类中的对象的共同属性和行为
- 对象：根据类创建的具体实例

```python
# 类的定义
class <类名>:
    <语句块>

# 类的实例化（用类创建对象）
<对象名> = <类名>()
```

### 例：病人类
```python
class Patient:
    def __init__(self,name,age):
        self.name = name
        self.age = age

# 注："__init__"称为构造函数，注意左右两边是双下划线

# 实例化
p1 = Patient("张三",45)
p2 = Patient("李四",35)

print(p1.age)
```

### 例：数据缩放

```python
import numpy as np

data = np.array([[25,80],[32,95],[18,65],[40,100]])

data_min = data.min(axis=0)
data_max = data.max(axis=0)

norm_data = (data-data_min)/(data_max-data_min)

print(norm_data)

```
