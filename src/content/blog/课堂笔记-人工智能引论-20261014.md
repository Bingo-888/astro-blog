## 机器学习概念

[诺奖得主中的机器学习名人：Hinton和Hassabis](https://blog.bingo888.top/post/%E8%AF%BE%E5%A0%82%E7%AC%94%E8%AE%B0-%E4%BA%BA%E5%B7%A5%E6%99%BA%E8%83%BD%E4%B8%8E%E4%BA%BA%E7%B1%BB%E7%A4%BE%E4%BC%9A-20261012#ai-for-science)

> **机器学习**的概念：程序在任务T上的性能，按照标准P来测量，会随着经验E的积累而提高。
> 
> $ 深度学习 \subseteq 机器学习 \subseteq 人工智能 $
> 
> **样本**：一个独立的观测或数据实例
> 
> **特征**：描述样本的若干属性
> 
> 例如：某个学生是**样本**，那么出勤率/作业平均分就是他的**特征** 
>
> **标签**：样本对应的结果/目标值/正确答案
>
> **模型**：从数据中学习到的映射规则，能将输入特征转换为输出结果。
>
> **训练**：让模型从数据中学习规律的过程
>
> **参数**：模型训练得到，反映数据的数量关系和规律
>
> **超参数**：人为添加，作为模型的训练规则
>
> **训练集**/**验证集**/**测试集**：三者严格隔离，模型训练过程中不能接触测试集的数据，以防结果失去可信度
>
> **学习算法**：从数据中生成模型的具体方法（如**线性回归算法** / **决策树算法**）

## 机器学习分类

- 监督学习
- 半监督学习
- 无监督学习
- 强化学习

> **监督学习**：模型从已标注数据训练，通过学习这些标签和输入的关系进行预测
>
> 监督学习的应用场景：身份验证 / 自然语言处理 / 医学诊断 / 气象预测
>
> **无监督学习**：模型从未标注数据训练，从数据中发现模式和结构（聚类算法 / 降维算法）
>
> **半监督学习**：模型从已标注和未标注的混合数据训练
>
> 半监督学习的应用场景：网页分类 / 医学影像分析 / 工业质检
>
> **强化学习**：研究智能体在未知环境中通过试错交互，以最大化长期累计奖励为目标，学习最优决策策略
>
> 强化学习的应用场景：机器人 / 游戏 / 智驾 / 自然语言处理 / 医疗

## 监督学习简介

监督学习的算法分类：

- 回归算法
- 分类算法（逻辑回归算法 / KNN算法 / 决策树算法）

监督学习的学习流程：

预处理 => 训练学习 => 验证 => 预测

## 监督学习的回归算法

> **一元线性回归模型**：$y = kx_1 + b$
> 
> **多元线性回归模型**：$y = k_1x_1+k_2x_2+......+b$
>
> （训练模型的过程就是拟合k值）
>
> **线性回归的均方误差（MSE）**：$MSE = \frac{1}{m}\Sigma^m_{i=1}(真实值y_i-预测值y_i)^2$
>
> **最小二乘法**求线性回归（略）
>
> **梯度下降法**求线性回归（略）
