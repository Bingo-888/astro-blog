## （复习）Python 的变量命名

- 可以使用数字/字母/下划线
- 第一个字符不能是数字
- 不能用Python的关键字作为变量名

## Python 的 For 循环

```python
for <循环变量> in <可迭代对象>:
    <循环体语句>
```

for循环用于遍历序列（元组/列表/字典/集合/字符串）和其他可迭代对象，依次取出其中每个元素并执行循环体
（字符串中的一个元素就是其中的一个字符）

### 例子：计算1-100的和

注：range()是Python的内置函数，输入值是3个整数（左边界/右边界/步长），输出值是一个整数列表。range的左边界是闭合的，右边界是开放的。
```python
s = 0
for i in range(1,101):
    s = s + i
print("1-100的和:",s)
```

### 例子：将号码与人名关联打印

注1：enumerate()是Python的内置函数，输入值是1个列表+1个整数，输出值是1个enumerate对象。

注2：此处的print(f"xxx{x}xxx")中，前面的f是Python语言的f-string语法（类似于C语言的printf中的f），可以将{x}在输出时替换为相应的变量

```python
names = ["Alice","Bob","John","Sam"]
for i,name in enumerate(names,1):
    print(f"第{i}号：{name}")
```

## Python 的 while 循环

while循环靠条件判断控制执行流程。条件成立时继续循环，条件不成立时终止循环

``` python
while <条件表达式>:
    <循环体语句>
```

### 例：水池的流入流出

情景：水池每小时流出15L，流入10L，几小时从200L降到50L以下？

```python
water = 200
h = 0
while water >= 50:
    water = water - 15 + 10
    h += 1
print(f"需{h}小时")
```

## Python循环结构中的 break 语句

break语句用于直接终止并跳出循环

### 例：用break跳出输入密码的while循环
```python
while True:
    pwd = input("请输入密码:")
    if (pwd == "123456abc"):
        print("True")
        break
    print("False")
```

## Python循环结构中的 continue 语句

continue语句用于终止本轮循环，开启下一轮循环

### 例：输出及格的成绩
```python
scores = [10,40,70,100]
for s in scores:
    if s < 60:
        continue
    print(f"及格成绩：{s}")
```

## Python 的 异常处理

### try 语句的使用

```python
try:
    <可能出现异常的代码>
except <异常类型>:
    <异常发生时执行的处理代码>
```

## Python 的 自定义函数

```python
def 函数名(输入值):
    函数体
    return 输出值
```

（准确的来说，输入值叫做参数，输出值叫做返回值）

## Python 模块与库

模块是一个有函数和变量的Python源代码文件。库则是许多模块的集合，完成特定的功能。

```python
import 库名
库名.函数名(输入值)
# 导入整个库，此时调用库中的函数需要在前面加库名
from 库名 import 函数名
函数名(输入值)
# 从某个库中导入特定函数，此时调用库中的函数无需在前面加库
```
